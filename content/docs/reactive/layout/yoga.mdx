## How it works

A flex container lines its children up along one axis, the **main axis**, which `FlexDirection` picks: a `Row`
runs left to right, a `Column` top to bottom. The other axis is the **cross axis**. Three things then decide where
each child ends up. `JustifyContent` spreads the children along the main axis when there is room to spare.
`AlignItems` places them across it, and `Stretch` makes them fill it. `Gap` keeps a distance between neighbours and
`Padding` keeps all of them away from the container's edges. When a row runs out of room, `FlexWrap` lets it continue
on a new line instead of overflowing.

Try them. The box below holds five blocks of different sizes, and every control writes a state that the container's
properties are bound to.

Two of the defaults differ from React Native and follow the web instead: a container is a row unless told otherwise,
and items don't shrink unless told to. `AlignItems` only has work to do when there is free space across the axis,
and so does `JustifyContent` along it. The blocks above set a `MinSize` rather than a `Size`, because a fixed size
can't stretch and a minimum can.

## Units

A size, padding, margin, gap or position is a `YogaValue`. `12.pt` is twelve points, which are Unity units, and a bare
`12f` means the same. `50.pct` is half of the parent. `YogaValue.Auto` sizes from the content and is the default.
The other Yoga keywords exist as `"fit-content"`, `"max-content"` and `"stretch"` strings or the `YogaValue` constants
of the same name.

A `YogaVector` holds a value per axis: `new() { x = 20.pt }` sets the width and leaves the height to the content, and a
single value, `Size = 7.pt`, sets both. A `YogaFrame` holds a value per edge, `new() { left = 2.pt, right = 2.pt }`,
and a single value fills all four.

## Growing and shrinking

An item's share of the leftover room is `FlexGrow`, and its share of the deficit when there isn't enough is
`FlexShrink`. `Flex = 1` is the shorthand you'll actually use: grow 1, shrink 1, basis 0, meaning take an equal share.
Two siblings with `Flex = 1` split a row. `Flex = 1` next to `Flex = 2` splits it one to two. A label filling the room
next to a button, a table filling the room next to its scrollbar, a page next to a sidebar: all `Flex = 1`. `MinSize`
and `MaxSize` clamp whatever the rest decided, which is also how you stop a growing item from being squeezed to
nothing.

class Growing : ReactiveComponent {
    protected override GameObject Construct() {
        var growA = Remember(1f);
        var growB = Remember(1f);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 2.pt
            },

            Children = {
                new Background {
                    FlexController = {
                        AlignItems = Align.Stretch,
                        Gap = 1.pt,
                        Padding = 1.pt
                    },

                    FlexItem = {
                        Size = new() { x = 90.pt, y = 12.pt }
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    Color = Color.white with { a = 0.08f },

                    Children = {
                        CreateBlock(
                            color: new Color(0.35f, 0.75f, 1f),
                            text: growA.Map(x => $"grow {x:0}"),
                            grow: growA
                        ),
                        CreateBlock(
                            color: new Color(1f, 0.55f, 0.75f),
                            text: growB.Map(x => $"grow {x:0}"),
                            grow: growB
                        ),

                        new Background {
                            FlexController = {
                                JustifyContent = Justify.Center,
                                AlignItems = Align.Center
                            },

                            FlexItem = {
                                Size = new() { x = 18.pt }
                            },

                            Sprite = BeatSaberResources.Sprites.background,
                            PixelsPerUnit = 10f,
                            Color = Color.white with { a = 0.3f },

                            Children = {
                                new Label { Text = "fixed", FontSize = 3f }
                            }
                        }
                    }
                },

                CreateSlider(
                    name: "A grows",
                    state: growA
                ),
                CreateSlider(
                    name: "B grows",
                    state: growB
                )
            }
        }.Use();
    }

    [StateGen]
    private static Background CreateBlock(
        Color color,
        IState<string> text,
        IState<float> grow
    ) {
        return new Background {
            FlexController = {
                JustifyContent = Justify.Center,
                AlignItems = Align.Center
            },

            FlexItem = {
                sFlexGrow = grow.In(),
                // A growing item still needs somewhere to start, and a floor
                // so it can't vanish
                FlexBasis = 0.pt,
                MinSize = new() { x = 6.pt }
            },

            Sprite = BeatSaberResources.Sprites.background,
            PixelsPerUnit = 10f,
            Color = color with { a = 0.8f },

            Children = {
                new Label {
                    sText = text.In(),
                    FontSize = 3f,
                    Color = Color.black
                }
            }
        };
    }

    [StateGen]
    private static Layout CreateSlider(string name, State<float> state) {
        return new Layout {
            FlexController = {
                AlignItems = Align.Center,
                Gap = 2.pt
            },

            Children = {
                new Label {
                    FlexItem = { Size = new() { x = 16.pt } },
                    Alignment = TextAlignmentOptions.Right,
                    FontSize = 3f,
                    Text = name,
                    Color = Color.white with { a = 0.7f }
                },

                new BsSlider {
                    FlexItem = { Size = new() { x = 40.pt, y = 6.pt } },
                    MinValue = 0f,
                    MaxValue = 3f,
                    ValueStep = 1f,
                    sValue = state,
                    OnValueChanged = x => state.Value = x
                }
            }
        };
    }

`Margin` pushes one item's neighbours and the container's edges away from that item. `AlignSelf` overrides the
container's `AlignItems` for one child. `AspectRatio` derives one axis from the other, so a box with only a height
and an aspect ratio of 1 is square.

## Absolute positioning

`PositionType.Absolute` takes an item out of the flow: its siblings are laid out as if it wasn't there, and
`Position` pins it by its distance from the parent's edges, in points or percents, counting only the edges you set.
A badge in a corner, a settings button the rest of the screen shouldn't know about, a progress fill behind a label
stretched with `{ left = 0.pt, top = 0.pt, bottom = 0.pt }` and a bound width, and anything that follows the pointer
are all this.

<Playground>
```csharp excerpt
new Background {
    FlexItem = {
        PositionType = PositionType.Absolute,
        Size = new() { x = 14.pt, y = 5.pt },
        sPosition = corner.Map(x => x switch {
            Corner.TopLeft => new YogaFrame { top = 1.pt, left = 1.pt },
            Corner.TopRight => new YogaFrame { top = 1.pt, right = 1.pt },
            Corner.BottomLeft => new YogaFrame { bottom = 1.pt, left = 1.pt },
            _ => new YogaFrame { bottom = 1.pt, right = 1.pt }
        })
    }
}
```

class Badge : ReactiveComponent {
    private enum Corner { TopLeft, TopRight, BottomLeft, BottomRight }

    protected override GameObject Construct() {
        var corner = Remember(Corner.TopRight);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 3.pt
            },

            Children = {
                new Background {
                    FlexController = {
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center,
                        Gap = 2.pt
                    },

                    FlexItem = {
                        Size = new() { x = 70.pt, y = 30.pt }
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    Color = Color.white with { a = 0.08f },

                    Children = {
                        // The flow: two blocks, laid out as if the badge
                        // wasn't there
                        CreateBlock(new Color(0.35f, 0.75f, 1f)),
                        CreateBlock(new Color(1f, 0.55f, 0.75f)),

                        new Background {
                            FlexController = {
                                JustifyContent = Justify.Center,
                                AlignItems = Align.Center
                            },

                            FlexItem = {
                                PositionType = PositionType.Absolute,
                                Size = new() { x = 14.pt, y = 5.pt },
                                sPosition = corner.Map(x => x switch {
                                    Corner.TopLeft => new YogaFrame {
                                        top = 1.pt,
                                        left = 1.pt
                                    },
                                    Corner.TopRight => new YogaFrame {
                                        top = 1.pt,
                                        right = 1.pt
                                    },
                                    Corner.BottomLeft => new YogaFrame {
                                        bottom = 1.pt,
                                        left = 1.pt
                                    },
                                    _ => new YogaFrame {
                                        bottom = 1.pt,
                                        right = 1.pt
                                    }
                                })
                            },

                            Sprite = BeatSaberResources.Sprites.background,
                            PixelsPerUnit = 10f,
                            Color = new Color(1f, 0.8f, 0.2f),

                            Children = {
                                new Label {
                                    Text = "NEW",
                                    FontSize = 2.8f,
                                    Color = Color.black
                                }
                            }
                        }
                    }
                },

                new BsSegmentedControl<Corner> {
                    FlexItem = { Size = new() { x = 64.pt, y = 6.pt } },
                    Items = new Dictionary<Corner, BsSegmentedControlItem> {
                        [Corner.TopLeft] = new("Top left", null),
                        [Corner.TopRight] = new("Top right", null),
                        [Corner.BottomLeft] = new("Bottom left", null),
                        [Corner.BottomRight] = new("Bottom right", null)
                    },
                    sKey = corner,
                    OnKeyChanged = x => corner.Value = x
                }
            }
        }.Use();
    }

    private static Background CreateBlock(Color color) {
        return new Background {
            FlexItem = {
                Size = new() { x = 20.pt, y = 14.pt }
            },

            Sprite = BeatSaberResources.Sprites.background,
            PixelsPerUnit = 10f,
            Color = color with { a = 0.8f }
        };
    }
}

An absolute item is still laid out by its parent, just not in the flow. To have the parent leave something alone
entirely, see [Layout System](/docs/reactive/layout/system#showing-hiding-and-opting-out).
`ConstrainHorizontal` and `ConstrainVertical` on a controller are Reactive's, not Yoga's, and only mean something on
a [root](/docs/reactive/layout/system#leaves-and-roots).
