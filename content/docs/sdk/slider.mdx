`BsSlider` is the game's slider with the increment buttons at each end. The showcase's *Slider* page:

<Playground preview="/assets/sdk/slider.gif">
```csharp excerpt
new BsSlider {
    sColors = colors,
    ValueStep = 0.01f,
    Value = 0.5f,
    ValueFormatter = x => $"{x * 100f:0}%"
},

new BsSlider {
    sColors = colors,
    MinValue = 0f,
    MaxValue = 10f,
    ValueStep = 1f,
    Value = 3f,
    ShowButtons = false
},

    sColors = colors,
    ValueStep = 0.05f,
    Value = 0.25f,
    ShowValueText = false

    MaxValue = 5f,
```

`MinValue` and `MaxValue` default to 0 and 1, `ValueStep` is the increment the buttons and the drag snap to, and
`ValueFormatter` turns the value into the readout. `ShowButtons` and `ShowValueText` hide the two extras.
`OnValueChanged` fires as the user drags.

The way to wire it to a state is the one you've been using since [Bindings](/docs/reactive/state/states):

```csharp
new BsSlider {
    MinValue = 0f,
    MaxValue = 10f,
    ValueStep = 1f,
    Value = level.Value,
    OnValueChanged = x => level.Value = Mathf.RoundToInt(x)
}
```

or `sValue = level` if the state should also move the slider. The showcase's color mixer is three of those, one per
channel, each with its handle recolored through the `with` pattern, feeding a `RememberDerived` that makes the color.
