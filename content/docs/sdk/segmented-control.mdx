title: "Segmented Control and Keyed Container"
description: A row or column of tabs with one selected, and the container that shows a page per tab.
---

`BsSegmentedControl<TKey>` is a set of cells, one of which is selected, keyed by whatever you like. The showcase's
*Segmented control* page shows the shapes it takes:

<Playground preview="/assets/sdk/segmented-control.gif">
```csharp excerpt
new BsSegmentedControl<int> {
    FlexController = {
        FlexDirection = FlexDirection.Column,
        Gap = 0.5f.pt
    },

    FlexItem = {
        Size = new() { x = 24.pt, y = 24.pt }
    },

    sColors = colors,
    Key = 0,
    Items = new Dictionary<int, BsSegmentedControlItem> {
        [0] = new("Edit", GameResources.EditIcon),
        [1] = new("Search", GameResources.SearchIcon),
        [2] = new("Close", GameResources.CloseIcon)
    }
},

new BsSegmentedControl<int> {
    FlexItem = {
        Size = new() { x = 30.pt, y = 7.pt }
    },

    sColors = colors,
    Key = 0,
    Items = new Dictionary<int, BsSegmentedControlItem> {
        [0] = new(null, GameResources.ArrowIcon),
        [1] = new(null, GameResources.CircleIcon),
        [2] = new(null, GameResources.CaretIcon)
    }
}
```

`Items` maps each key to a `BsSegmentedControlItem(text, icon)`, and either can be null. `Key` is the selected one,
`OnKeyChanged` reports a change. The control is a layout controller holder, so `FlexController` decides whether it's
a row or a column, and the cells pick their rounded corners from the direction.

The thing it's usually paired with is `KeyedContainer<TKey>`, which shows one view per key:

<Playground preview="/assets/sdk/keyed-container.gif">
```csharp excerpt
var page = Remember(Page.Buttons);

new BsSegmentedControl<Page> {
    Items = items,
    Key = page.Value,
    OnKeyChanged = x => page.Value = x
},

new KeyedContainer<Page> {
    FlexItem = {
        Flex = 1
    },

    sKey = page,
    Views = new Dictionary<Page, IReactiveComponent> {
        [Page.Buttons] = new ButtonsPage(),
        [Page.Toggle] = new TogglePage()
    }
}
```
```csharp
class Pages : ReactiveComponent {
    private enum Page { Buttons, Toggle, Slider }

    protected override GameObject Construct() {
        var page = Remember(Page.Toggle);

        return new Layout {
            FlexController = {
                AlignItems = Align.Center,
                JustifyContent = Justify.Center
            },

            Children = {
                new Layout {
                    FlexController = {
                        AlignItems = Align.Stretch,
                        Gap = 2.pt
                    },

                    FlexItem = {
                        Size = new() { x = 90.pt, y = 40.pt }
                    },

                    Children = {
                        new BsSegmentedControl<Page> {
                            FlexController = {
                                FlexDirection = FlexDirection.Column,
                                Gap = 0.5f.pt
                            },

                            FlexItem = {
                                Size = new() { x = 22.pt }
                            },

                            Items = new Dictionary<Page, BsSegmentedControlItem> {
                                [Page.Buttons] = new("Buttons", null),
                                [Page.Toggle] = new("Toggle", null),
                                [Page.Slider] = new("Slider", null)
                            },
                            Key = page.Value,
                            OnKeyChanged = x => page.Value = x
                        },

                        new KeyedContainer<Page> {
                            FlexController = {
                                AlignItems = Align.Stretch
                            },

                            FlexItem = {
                                Flex = 1
                            },

                            sKey = page,
                            Views = new Dictionary<Page, IReactiveComponent> {
                                [Page.Buttons] = CreatePage(
                                    title: "Buttons page",
                                    content: new BsTextButton {
                                        Text = "A button"
                                    }
                                ),
                                [Page.Toggle] = CreatePage(
                                    title: "Toggle page",
                                    content: new BsToggle { Toggled = true }
                                ),
                                [Page.Slider] = CreatePage(
                                    title: "Slider page",
                                    content: new BsSlider {
                                        FlexItem = {
                                            Size = new() { x = 40.pt, y = 7.pt }
                                        },
                                        Value = 0.4f
                                    }
                                )
                            }
                        }
                    }
                }
            }
        }.Use();
    }

    private static Background CreatePage(string title, ILayoutItem content) {
        return new Background {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 2.pt,
                Padding = 2.pt
            },

            FlexItem = {
                Flex = 1
            },

            Sprite = BeatSaberResources.Sprites.background,
            PixelsPerUnit = 10f,
            Color = Color.white with { a = 0.1f },

            Children = {
                new Label {
                    Text = title,
                    FontSize = 4f,
                    FontStyle = FontStyles.Bold
                },
                content
            }
        };
    }
}
```
</Playground>


The control writes `page`, the container reads it, and the view for the current key is enabled while the others are
disabled. `DummyView` is shown when the key has no view. The showcase wraps each page in a `LazyView` so it's built
the first time its tab is picked rather than all at once, which is worth doing when the pages are heavy.

## Properties

These are `BsSegmentedControl<T>`'s. `KeyedContainer<TKey>` takes a required `Views` dictionary, a required `Key`, an optional `DummyView` shown when the key has no view, and `OnKeyChanged`. Every property with a setter also has an `s`-version that takes a state.
