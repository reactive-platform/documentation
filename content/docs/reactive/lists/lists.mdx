## Cells and reuse

A list in Reactive is a `Repeater` or a `Table`. You give it the items and a function that builds one cell, and it
keeps the cells in step with the items. Add and remove names here, and keep an eye on how many cells get built:

<Playground preview="/assets/lists/repeater.webp">
```csharp excerpt
new Repeater<string, Background> {
    FlexController = {
        FlexDirection = FlexDirection.Row,
        FlexWrap = Wrap.Wrap,
        Gap = 1.pt
    },

    sItems = names,

    ConstructCell = context => {
        // Only runs when there are more items than cells
        built.Value++;

        return CreateChip(context);
    }
}
```
```csharp
class Squad : ReactiveComponent {
    private static readonly string[] AllNames = [
        "Ada", "Linus", "Grace", "Dennis", "Margaret",
        "Alan", "Barbara", "Ken", "Frances", "Donald"
    ];

    protected override GameObject Construct() {
        var names = Remember<IReadOnlyList<string>>(AllNames[..5]);
        var built = Remember(0);

        var summary = RememberDerived(
            names,
            built,
            predicate: (x, y) => $"{x.Count} names, {y} cells built"
        );

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 2.pt
            },

            Children = {
                // A fixed width, so the chips wrap onto new rows as the
                // list grows instead of running out of the view
                new Background {
                    FlexController = {
                        Padding = 2.pt
                    },

                    FlexItem = {
                        Size = new() { x = 72.pt }
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    Color = Color.white with { a = 0.06f },

                    Children = {
                        new Repeater<string, Background> {
                            FlexController = {
                                FlexDirection = FlexDirection.Row,
                                FlexWrap = Wrap.Wrap,
                                JustifyContent = Justify.Center,
                                Gap = 1.pt
                            },

                            FlexItem = {
                                FlexGrow = 1f
                            },

                            sItems = names,

                            ConstructCell = context => {
                                // Only runs with more items than cells
                                built.Value++;

                                return CreateChip(context);
                            }
                        }
                    }
                },

                new Label {
                    FontSize = 3f,
                    Color = Color.white with { a = 0.6f },
                    sText = summary
                },

                new Layout {
                    FlexController = {
                        Gap = 2.pt
                    },

                    Children = {
                        new BsTextButton {
                            Text = "Add",
                            OnClick = () => names.Value = AllNames
                                .Take(names.Value.Count + 1)
                                .ToArray()
                        },

                        new BsTextButton {
                            Text = "Remove",
                            OnClick = () => names.Value = AllNames
                                .Take(Math.Max(names.Value.Count - 1, 0))
                                .ToArray()
                        }
                    }
                }
            }
        }.Use();
    }

    // Everything the item decides comes from the context, so a reused cell
    // takes on the color and name of its new item
    [StateGen]
    private static Background CreateChip(CellContext<string> context) {
        var color = context.Map(x => GetColor(x.Item));

        return new Background {
            FlexController = {
                AlignItems = Align.Center,
                Gap = 1.pt,
                Padding = new() {
                    left = 1.pt,
                    right = 2.pt,
                    top = 1.pt,
                    bottom = 1.pt
                }
            },

            Sprite = BeatSaberResources.Sprites.background,
            PixelsPerUnit = 10f,
            sColor = color.Map(x => x with { a = 0.25f }),

            Children = {
                new Background {
                    FlexController = {
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center
                    },

                    FlexItem = {
                        Size = 4.pt
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 30f,
                    sColor = color,

                    Children = {
                        new Label {
                            FontSize = 2.6f,
                            Color = Color.black,
                            sText = context.Map(x => x.Item[..1])
                        }
                    }
                },

                new Label {
                    FontSize = 3f,
                    sText = context.Map(x => x.Item)
                }
            }
        };
    }

    private static Color GetColor(string name) {
        var hue = Array.IndexOf(AllNames, name) * 0.1f;
        return Color.HSVToRGB(hue, 0.55f, 1f);
    }
}
```
</Playground>

Remove a few names and add them back, and the counter stays where it was, since it only grows when the list gets
longer than it has ever been. That works because the repeater reuses its cells. It builds one only when there are more
items than cells, disables the spare ones when there are fewer, and enables them again when the list grows.

The two type arguments are the item type and the cell type. `Items` takes the whole list, so changing it means assigning
a new one, and the repeater has no `Add` or `Remove`. Its `FlexController` lays the cells out like any other children,
as a column, a row or a wrapping grid.

A cell doesn't get the item itself but a `CellContext<T>`, a [state](/docs/reactive/state/states) with these members:

- `Item` is the item the cell shows right now.
- `Index` is its position in the list, and `TotalCells` how many items there are.
- `Selected` tells whether the item is selected, and setting it selects or deselects the item.
- `UpdateType` tells whether the last change was to the item or to the selection.

When a cell is reused, it gets the new item through the same context, which notifies like any state. The cell's
bindings then show the new item, so nothing is rebuilt. That makes one rule important: a cell has to read everything it
shows from the context.

A cell that sets its text once from the item compiles and looks right at first. Below, the same list is shown with that
cell and with one that maps its text, so reverse it and compare the two:

<Playground preview="/assets/lists/reuse.webp">
```csharp excerpt
// Set once, so a reused cell keeps showing its first item
construct: context => new Label {
    Text = context.Item
}

// Follows whatever item the cell is handed
construct: context => new Label {
    sText = context.Map(x => x.Item)
}
```
```csharp
class Reuse : ReactiveComponent {
    protected override GameObject Construct() {
        var names = Remember<IReadOnlyList<string>>([
            "Ada",
            "Linus",
            "Grace",
            "Dennis"
        ]);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 3.pt
            },

            Children = {
                new Layout {
                    FlexController = {
                        Gap = 10.pt
                    },

                    Children = {
                        CreateColumn(
                            title: "Text",
                            names: names,
                            // Set once, so a reused cell keeps showing its
                            // first item
                            construct: context => new Label {
                                Text = context.Item
                            }
                        ),

                        CreateColumn(
                            title: "sText",
                            names: names,
                            // Follows whatever item the cell is handed
                            construct: context => new Label {
                                sText = context.Map(x => x.Item)
                            }
                        )
                    }
                },

                new BsTextButton {
                    Text = "Reverse",
                    OnClick = () => names.Value = names.Value
                        .Reverse()
                        .ToArray()
                }
            }
        }.Use();
    }

    [StateGen]
    private static Layout CreateColumn(
        string title,
        IState<IReadOnlyList<string>> names,
        Func<CellContext<string>, Label> construct
    ) {
        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                Gap = 1.pt
            },

            Children = {
                new Label {
                    Text = title,
                    FontSize = 3f,
                    Color = Color.white with { a = 0.6f }
                },

                new Repeater<string, Label> {
                    FlexController = {
                        FlexDirection = FlexDirection.Column,
                        AlignItems = Align.Center,
                        Gap = 0.5f.pt
                    },

                    sItems = names.In(),
                    ConstructCell = construct
                }
            }
        };
    }
}
```
</Playground>

After a reverse, the Text column still lists the names in their first order, because each label got its text once and
its cell was then handed a different item. The sText column follows the list, since its labels map the context. The
same goes for anything else that depends on the item, like a color from a status or an icon from a type.

## Tables and scrolling

A repeater builds a cell for every item, which is fine for twenty items but not for ten thousand. A `Table` builds only
as many cells as fit on screen, and as you scroll, it moves them from one end to the other with new items. Scroll
through these ten thousand rows and click one:

<Playground preview="/assets/lists/table.webp">
```csharp excerpt
var scroll = new ScrollContext();
var rows = Enumerable.Range(0, 10000).ToArray();

new Table<int, Background> {
    ScrollContext = scroll,
    Items = rows,
    ConstructCell = CreateRow
},

new Scrollbar {
    ScrollContext = scroll
}
```
```csharp
class Rows : ReactiveComponent {
    private static readonly Color SelectedColor = new(0.35f, 0.75f, 1f);

    protected override GameObject Construct() {
        var scroll = new ScrollContext();
        var rows = Enumerable.Range(0, 10000).ToArray();

        return new Layout {
            FlexController = {
                AlignItems = Align.Stretch,
                JustifyContent = Justify.Center,
                Gap = 1.pt
            },

            Children = {
                new Table<int, Background> {
                    FlexItem = {
                        Size = new() { x = 60.pt, y = 50.pt }
                    },

                    ScrollContext = scroll,
                    Items = rows,
                    ConstructCell = CreateRow
                },

                new Scrollbar {
                    ScrollContext = scroll
                }
            }
        }.Use();
    }

    [StateGen]
    private static Background CreateRow(CellContext<int> context) {
        return new Background {
            FlexController = {
                AlignItems = Align.Center,
                Padding = new() { left = 2.pt, right = 2.pt }
            },

            // Every row has the same height, which the table relies on
            FlexItem = {
                Size = new() { y = 6.pt }
            },

            Sprite = BeatSaberResources.Sprites.background,
            PixelsPerUnit = 10f,
            sColor = context.Map(x => x.Selected
                ? SelectedColor
                : Color.white with {
                    a = x.Index % 2 == 0 ? 0.08f : 0.14f
                }
            ),

            Do = x => x.WithPointerEvents(
                onDown: _ => context.Selected = true
            ),

            Children = {
                new Label {
                    Alignment = TextAlignmentOptions.Left,
                    sText = context.Map(x => $"Row {x.Item + 1}"),
                    sColor = context.Map(x => x.Selected
                        ? Color.black
                        : Color.white
                    )
                }
            }
        };
    }
}
```
</Playground>

Only a dozen cells exist here, and each one gets a new row number as it comes back into view. The table measures its
first cell to know how many fit, so every cell has to be the same size along the scroll axis. Otherwise it works like a
repeater, with the same `Items`, `ConstructCell` and selection, and `ScrollOrientation` turns it sideways.

Scrolling goes through a `ScrollContext`, a state shared by everything that cares about the same scroll position. The
table writes it as you scroll, and the `Scrollbar` reads it to place its thumb and writes it when you drag. The table
takes it as a plain property rather than a binding, since it needs the context itself and not only its value. Your code
can move it too:

- `ScrollTo` and `ScrollRelative` move to a position or by an offset.
- `PageUp`, `PageDown`, `LineUp` and `LineDown` move by a page or by a cell.

Each of them takes an `immediately` flag that skips the animation.

## Selection

Lists also track which items are selected, and both ends of that go through the context. A cell selects itself by
setting `context.Selected` and reads the same flag back to look selected, as these chips do:

<Playground preview="/assets/lists/selection.webp">
```csharp excerpt
var selection = Remember<IReadOnlyCollection<string>>(initial);

new Repeater<string, Background> {
    // The mode comes first, since Single would reject two items
    SelectionMode = SelectionMode.Multiple,
    SelectedItems = initial,
    OnSelectedItemsChanged = x => selection.Value = x.ToArray(),

    Items = difficulties,
    ConstructCell = context => new Background {
        sColor = context.Map(x => x.Selected
            ? SelectedColor
            : Color.white with { a = 0.12f }
        ),

        Do = x => x.WithPointerEvents(
            onDown: _ => context.Selected = !context.Selected
        )
    }
}

new Label {
    Color = Color.white with { a = 0.6f },
    sText = selection.Map(x => x.Count == 0
        ? "Nothing selected"
        : $"Selected: {string.Join(", ", x)}"
    )
}
```
```csharp
class Chips : ReactiveComponent {
    private static readonly Color SelectedColor = new(0.35f, 0.75f, 1f);

    protected override GameObject Construct() {
        string[] difficulties = ["Easy", "Normal", "Hard", "Expert", "Expert+"];
        string[] initial = ["Hard", "Expert"];

        var selection = Remember<IReadOnlyCollection<string>>(initial);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 3.pt
            },

            Children = {
                new Repeater<string, Background> {
                    FlexController = {
                        FlexDirection = FlexDirection.Row,
                        Gap = 1.pt
                    },

                    // The mode comes first, since Single would reject two items
                    SelectionMode = SelectionMode.Multiple,
                    SelectedItems = initial,
                    OnSelectedItemsChanged = x => selection.Value = x.ToArray(),

                    Items = difficulties,
                    ConstructCell = context => new Background {
                        FlexController = {
                            Padding = new() {
                                left = 2.pt,
                                right = 2.pt,
                                top = 1.pt,
                                bottom = 1.pt
                            }
                        },

                        Sprite = BeatSaberResources.Sprites.background,
                        PixelsPerUnit = 10f,
                        sColor = context.Map(x => x.Selected
                            ? SelectedColor
                            : Color.white with { a = 0.12f }
                        ),

                        Do = x => x.WithPointerEvents(
                            onDown: _ => context.Selected = !context.Selected
                        ),

                        Children = {
                            new Label {
                                sText = context.Map(x => x.Item),
                                sColor = context.Map(x => x.Selected
                                    ? Color.black
                                    : Color.white
                                )
                            }
                        }
                    }
                },

                new Label {
                    Color = Color.white with { a = 0.6f },
                    sText = selection.Map(x => x.Count == 0
                        ? "Nothing selected"
                        : $"Selected: {string.Join(", ", x)}"
                    )
                }
            }
        }.Use();
    }
}
```
</Playground>

Hard and Expert start selected, and clicking a chip toggles it while the label lists the selection. On the list itself,
`SelectionMode` decides what a cell selecting itself means:

- `Single`, the default, replaces the previous selection.
- `Multiple` adds to the selection.
- `None` ignores it, for lists that aren't selectable at all.

`SelectedItems` reads or replaces the selection from code, and it throws when the count doesn't fit the mode, such as two
items in `Single`. `OnSelectedItemsChanged` reports the whole selection after every change, and switching to `Single`
with several items selected keeps only one of them.

Selection is tracked by item rather than by cell, which is what lets it survive reuse and scrolling. When a selected row
scrolls out of the table above, its cell gets another row and shows it unselected, and whichever cell receives the row
when it scrolls back shows it selected again. It also means equal items count as the same item, so a list with
duplicates selects them together.
