## Pointer events

Reactive has no input system of its own, and input comes from Unity's event system. The library only adds a way to
attach handlers to a graphic, along with the habit of turning what they report into state.

`WithPointerEvents` attaches a handler to any graphic component, meaning anything with an image or text the event system
can hit. Try this demo, where a box logs every event it gets and shows the handler's flags below it:

<Playground preview="/assets/input/pointer-events.webp">
```csharp excerpt
var graphic = Remember(GraphicState.None);

new Background {
    sColor = graphic.MapColorSet(Colors),

    Do = x => x.WithPointerEvents(
        onEnter: _ => Log("enter"),
        onLeave: _ => Log("leave"),
        onDown: _ => Log("down"),
        onUp: _ => Log("up"),

        // Runs after every other callback
        onUpdate: h => {
            graphic.IsHovered = h.IsHovered;
            graphic.IsActive = h.IsPressed;
        }
    )
}
```
```csharp
class PointerEvents : ReactiveComponent {
    private const int LogSize = 4;

    private static readonly ColorSet Colors = new() {
        Color = Color.white with { a = 0.1f },
        HoveredColor = new Color(0f, 0.75f, 1f, 0.6f),
        ActiveColor = new Color(1f, 0.2f, 0.8f, 0.8f)
    };

    private readonly record struct Entry(int Number, string Text);

    private State<IReadOnlyList<Entry>> _log = null!;
    private int _count;

    protected override GameObject Construct() {
        _log = Remember<IReadOnlyList<Entry>>([]);

        var graphic = Remember(GraphicState.None);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 2.pt
            },

            Children = {
                new Background {
                    FlexController = {
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center
                    },

                    FlexItem = {
                        Size = new() { x = 40.pt, y = 11.pt }
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    sColor = graphic.MapColorSet(Colors),

                    Do = x => x.WithPointerEvents(
                        onEnter: _ => Log("enter"),
                        onLeave: _ => Log("leave"),
                        onDown: _ => Log("down"),
                        onUp: _ => Log("up"),
                        onDragBegin: _ => Log("drag begin"),
                        onDragEnd: _ => Log("drag end"),
                        onScroll: h => Log(
                            $"scroll {h.EventData?.scrollDelta.y:0.0}"
                        ),

                        // Runs after every other callback
                        onUpdate: h => {
                            graphic.IsHovered = h.IsHovered;
                            graphic.IsActive = h.IsPressed;
                        }
                    ),

                    Children = {
                        new Label {
                            Text = "Hover, click, drag, scroll",
                            FontSize = 3.5f
                        }
                    }
                },

                new Label {
                    FontSize = 3f,
                    sText = graphic.Map(x =>
                        $"hovered {Mark(x.IsHovered)}   pressed {Mark(x.IsActive)}"
                    )
                },

                new Label {
                    FontSize = 2.8f,
                    Color = Color.white with { a = 0.7f },
                    sText = _log.Map(x => string.Join(
                        "   ·   ",
                        x.Select(y => $"{y.Number}. {y.Text}")
                    ))
                }
            }
        }.Use();
    }

    private void Log(string text) {
        var log = _log.Value.Append(new Entry(++_count, text));
        var overflow = _log.Value.Count + 1 - LogSize;
        _log.Value = log.Skip(Math.Max(0, overflow)).ToArray();
    }

    private static string Mark(bool value) => value ? "yes" : "no";
}
```
</Playground>

Hover the box, click it, drag across it and scroll over it, and watch the log and the flags change. Each callback
receives the handler, which keeps `IsHovered`, `IsPressed`, `IsDragging` and the latest event data from Unity, and each
one runs at a different point of an interaction:

- `onEnter` when the pointer moves onto the graphic or a child from outside them.
- `onLeave` when the pointer leaves the graphic and its children.
- `onDown` when a press starts over it, unless a child with its own handler takes it.
- `onUp` when that press ends, wherever the pointer is, so every `onDown` gets an `onUp`.
- `onDragBegin` once a press moves past the drag threshold.
- `onDrag` on every move during a drag, even over other graphics.
- `onDragEnd` when a drag is released, right after `onUp`.
- `onScroll` on a scroll, which goes to the parent when this callback is missing.
- `onUpdate` after each of the others and on moves, every hovered frame in the game.

If the object is disabled in the middle of an interaction, the handler sends the matching leave, up and drag end
itself, so no state gets stuck.

## Interaction state

The first demo already used the two types every interactive component in the SDK is built from. The first,
`GraphicState`, holds the flags for hovered, active and not interactable, and its properties flip one flag at a time on
a state that holds it. The second, `ColorSet`, turns those flags into a color, with one for each combination and a
fallback to the closest one you set, then to the plain `Color`. `MapColorSet` connects the two by turning a graphic
state into a color state you can bind.

Below you can see a button built from both, with a toggle that turns off its interactability:

<Playground preview="/assets/input/own-button.webp">
```csharp excerpt
static readonly ColorSet colors = new() {
    Color = new Color(1f, 1f, 1f, 0.1f),
    HoveredColor = new Color(0f, 0.75f, 1f, 0.5f),
    ActiveColor = new Color(0f, 0.75f, 1f, 0.9f),
    NotInteractableColor = new Color(1f, 1f, 1f, 0.03f)
};

var graphic = Remember(GraphicState.None);

new Background {
    sColor = graphic.MapColorSet(colors),

    Do = x => x.WithPointerEvents(
        onEnter: _ => graphic.IsHovered = true,
        onLeave: _ => graphic.IsHovered = false,
        onDown: _ => graphic.IsActive = true,
        onUp: _ => graphic.IsActive = false
    )
}
```
```csharp
class OwnButton : ReactiveComponent {
    // One color per state, missing ones fall back to the plain color
    private static readonly ColorSet backgroundColors = new() {
        Color = new Color(1f, 1f, 1f, 0.1f),
        HoveredColor = new Color(0f, 0.75f, 1f, 0.5f),
        ActiveColor = new Color(0f, 0.75f, 1f, 0.9f),
        NotInteractableColor = new Color(1f, 1f, 1f, 0.03f)
    };

    private static readonly ColorSet textColors = new() {
        Color = Color.white,
        NotInteractableColor = Color.white with { a = 0.3f }
    };

    protected override GameObject Construct() {
        var graphic = Remember(GraphicState.None);
        var clicks = Remember(0);

        var scale = RememberAnimated(1f, 120.ms, AnimationCurve.EaseOutCubic);
        graphic.AddCallback(x => scale.TargetValue = x.IsActive ? 0.92f : 1f);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 3.pt
            },

            Children = {
                new Background {
                    FlexController = {
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center
                    },

                    FlexItem = {
                        Size = new() { x = 34.pt, y = 9.pt }
                    },

                    ContentTransform = {
                        slocalScale = scale.Map(x => Vector3.one * x)
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    sColor = graphic.MapColorSet(backgroundColors),

                    Do = x => x.WithPointerEvents(
                        onEnter: _ => graphic.IsHovered = true,
                        onLeave: _ => graphic.IsHovered = false,
                        onDown: _ => {
                            graphic.IsActive = true;

                            if (graphic.IsInteractable) {
                                clicks.Value++;
                            }
                        },
                        onUp: _ => graphic.IsActive = false
                    ),

                    Children = {
                        new Label {
                            FontSize = 4f,
                            sText = clicks.Map(x => $"Clicked {x}"),
                            sColor = graphic.MapColorSet(textColors)
                        }
                    }
                },

                new BsToggle {
                    Toggled = true,
                    OnToggleStateChanged = x => graphic.IsInteractable = x
                }.InNamedRail("Interactable"),

                new Label {
                    FontSize = 3f,
                    Color = Color.white with { a = 0.6f },
                    sText = graphic.Map(x =>
                        $"hovered {x.IsHovered}   active {x.IsActive}   " +
                        $"interactable {x.IsInteractable}"
                    )
                }
            }
        }.Use();
    }
}
```
</Playground>

Hover and press the button, then switch it off with the toggle, and its color and press scale follow without any handler
knowing about the toggle. That works because the pointer events only flip flags and everything else reads them: the
background and the label each pass the flags through their own color set, and the press scale is an animated state
reading the same flags. So switching the button off is just `graphic.IsInteractable = false`, and every color set
reacts to it with no special case anywhere. The SDK's components work the same way, with a `Colors` record that holds
one color set for each part of a component.

## Input that lasts

Events tell you when a press starts and ends, but a hold is about what happens in between, and that takes time. So the event is stored as state, and something that runs over time, an animation or `OnUpdate`, does the
rest.

For a hold, `onDown` sets a pressed state and `onUp` and `onLeave` clear it. An animated progress then fills while it's
set and drains when it's cleared, and finishing a fill confirms once, as this hold-to-confirm button shows:

<Playground preview="/assets/input/hold.webp">
```csharp excerpt
pressed.AddCallback(x => {
    progress.Timing = x ? 1200.ms : (progress.Value * 1200 / 3f).ms;
    progress.TargetValue = x ? 1f : 0f;
});

// Drop the press once full, so the bar drains even if still held
progress.OnFinish = x => {
    if (x >= 1f) {
        confirmed.Value++;
        pressed.Value = false;
    }
};

new Background {
    Do = x => x.WithPointerEvents(
        onDown: _ => pressed.Value = true,
        onUp: _ => pressed.Value = false,
        onLeave: _ => pressed.Value = false
    )
}
```
```csharp
class HoldToConfirm : ReactiveComponent {
    protected override GameObject Construct() {
        var pressed = Remember(false);
        var confirmed = Remember(0);
        var progress = RememberAnimated(0f, 1200.ms);

        pressed.AddCallback(x => {
            progress.Timing = x ? 1200.ms : (progress.Value * 1200 / 3f).ms;
            progress.TargetValue = x ? 1f : 0f;
        });

        // Drop the press once full, so the bar drains even if still held
        progress.OnFinish = x => {
            if (x >= 1f) {
                confirmed.Value++;
                pressed.Value = false;
            }
        };

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 3.pt
            },

            Children = {
                new Background {
                    FlexController = {
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center
                    },

                    FlexItem = {
                        Size = new() { x = 44.pt, y = 9.pt }
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    Color = Color.white with { a = 0.1f },

                    Do = x => x.WithPointerEvents(
                        onDown: _ => pressed.Value = true,
                        onUp: _ => pressed.Value = false,
                        onLeave: _ => pressed.Value = false
                    ),

                    Children = {
                        new Background {
                            FlexItem = {
                                PositionType = PositionType.Absolute,
                                Position = new() {
                                    left = 0.pt,
                                    top = 0.pt,
                                    bottom = 0.pt
                                },
                                sSize = progress.Map(x => new YogaVector(
                                    (x * 100).pct,
                                    YogaValue.Auto
                                ))
                            },

                            Sprite = BeatSaberResources.Sprites.background,
                            PixelsPerUnit = 10f,
                            Color = new Color(1f, 0.3f, 0.4f, 0.7f)
                        },

                        new Label {
                            FontSize = 3.5f,
                            sText = pressed.Map(x => x
                                ? "Keep holding..."
                                : "Hold to delete"
                            )
                        }
                    }
                },

                new Label {
                    FontSize = 3.2f,
                    Color = Color.white with { a = 0.6f },
                    sText = confirmed.Map(x => x == 0
                        ? "Nothing deleted yet"
                        : $"Deleted {x} time{(x == 1 ? "" : "s")}"
                    )
                }
            }
        }.Use();
    }
}
```
</Playground>

Let go early and the bar drains three times faster than it filled. The drain time is set from how full the bar is, so
it keeps that speed from wherever you let go, while a fixed time would make an almost empty bar crawl back as slowly as
a full one. If you hold to the end instead, the button confirms and drops the press, so the bar drains even while you
keep holding, and deleting again takes a new press.

## Dragging

Hover and move events reach an object only while the pointer is over it or one of its children, but drag events don't
depend on that. Once a press moves past the drag threshold, the input module sends drag events to the pressed object
whenever the pointer moves, until the button is released, even while the pointer is over other graphics. So following
the pointer only takes turning each event into a position in the pressed object's own space, which
`InverseTransformPoint` does with the point the pointer's raycast hit.

The pad below makes that position the end of a glide, so press anywhere on it and drag past its edges:

<Playground preview="/assets/input/drag.webp">
```csharp excerpt
var from = Remember(Vector2.zero);
var to = Remember(Vector2.zero);
var progress = RememberAnimated(
    0f,
    200.ms,
    AnimationCurve.EaseOutCubic
);

// The knob's offset from the center of the pad
var offset = RememberDerived(
    from,
    to,
    progress,
    predicate: (a, b, t) => Vector2.Lerp(a, b, t)
);

// Starts a glide from wherever the knob is now
void GlideTo(Vector2 point) {
    from.Value = offset.Value;
    to.Value = point;
    progress.SetValueImmediate(0f);
    progress.TargetValue = 1f;
}

new Background {
    // Drag events keep coming after the pointer leaves the pad
    Do = x => x.WithPointerEvents(
        onDown: h => GlideTo(ToOffset(h)),
        onDrag: h => to.Value = ToOffset(h),
        onUp: _ => GlideTo(Vector2.zero)
    )
}

// The pointer's offset from the pad's center, clamped to the pad
private static Vector2 ToOffset(PointerEventsHandler handler) {
    var rect = ((RectTransform)handler.transform).rect;
    var world = handler.EventData!.pointerCurrentRaycast.worldPosition;

    Vector2 local = handler.transform.InverseTransformPoint(world);
    local -= rect.center;

    var maxX = (rect.width - KnobSize) / 2f;
    var maxY = (rect.height - KnobSize) / 2f;

    return new Vector2(
        Mathf.Clamp(local.x, -maxX, maxX),
        Mathf.Clamp(local.y, -maxY, maxY)
    );
}
```
```csharp
class DragKnob : ReactiveComponent {
    private const float KnobSize = 6f;

    protected override GameObject Construct() {
        var from = Remember(Vector2.zero);
        var to = Remember(Vector2.zero);
        var progress = RememberAnimated(
            0f,
            200.ms,
            AnimationCurve.EaseOutCubic
        );

        // The knob's offset from the center of the pad
        var offset = RememberDerived(
            from,
            to,
            progress,
            predicate: (a, b, t) => Vector2.Lerp(a, b, t)
        );

        // Starts a glide from wherever the knob is now
        void GlideTo(Vector2 point) {
            from.Value = offset.Value;
            to.Value = point;
            progress.SetValueImmediate(0f);
            progress.TargetValue = 1f;
        }

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 3.pt
            },

            Children = {
                new Background {
                    FlexController = {
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center
                    },

                    FlexItem = {
                        Size = new() { x = 40.pct, y = 50.pct }
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    Color = Color.white with { a = 0.1f },

                    // Drag events keep coming after the pointer leaves the pad
                    Do = x => x.WithPointerEvents(
                        onDown: h => GlideTo(ToOffset(h)),
                        onDrag: h => to.Value = ToOffset(h),
                        onUp: _ => GlideTo(Vector2.zero)
                    ),

                    Children = {
                        new Image {
                            // Unity's y goes up, the layout's top goes down
                            FlexItem = {
                                Size = KnobSize.pt,
                                sPosition = offset.Map(x => new YogaFrame {
                                    left = x.x.pt,
                                    top = (-x.y).pt
                                })
                            },

                            Sprite = GameResources.CircleIcon,
                            PreserveAspect = true,
                            Color = new Color(0f, 0.75f, 1f)
                        }
                    }
                },

                new Label {
                    FontSize = 3.2f,
                    Color = Color.white with { a = 0.6f },
                    sText = offset.Map(x => $"offset {x.x:0}, {x.y:0}")
                }
            }
        }.Use();
    }

    // The pointer's offset from the pad's center, clamped to the pad
    private static Vector2 ToOffset(PointerEventsHandler handler) {
        var rect = ((RectTransform)handler.transform).rect;
        var world = handler.EventData!.pointerCurrentRaycast.worldPosition;

        Vector2 local = handler.transform.InverseTransformPoint(world);
        local -= rect.center;

        var maxX = (rect.width - KnobSize) / 2f;
        var maxY = (rect.height - KnobSize) / 2f;

        return new Vector2(
            Mathf.Clamp(local.x, -maxX, maxX),
            Mathf.Clamp(local.y, -maxY, maxY)
        );
    }
}
```
</Playground>

The knob glides to where you press and sticks to the pointer once it gets there. Past the pad's edges it slides along
them instead of freezing, since the drag events keep coming. That works because the knob's position is a blend from
where it was to where the pointer is, and only the blend is animated. A drag moves the end of the blend without
restarting it, so the glide always takes the same time, and letting go is the same glide toward the center. The end
itself is clamped to the pad's rect as it is at that moment, so the pad can take any size, and here it stretches with
the window.

## Scrolling

Scrolling arrives like the other events, through `onScroll`, with the wheel's movement in the event data's
`scrollDelta`. Its y is positive when the wheel turns up and negative when it turns down, while its size depends on the
mouse and the system settings, so the same notch can arrive as a whole step or a fraction of one. That makes the sign
the only part worth trusting, and this number steps by one for each scroll in either direction:

<Playground preview="/assets/input/scroll.webp">
```csharp excerpt
Do = x => x.WithPointerEvents(onScroll: h => {
    var delta = h.EventData?.scrollDelta.y ?? 0f;

    if (delta != 0f) {
        value.Value = Mathf.Clamp(
            value.Value + (delta > 0f ? 1 : -1),
            Min,
            Max
        );
    }
})
```
```csharp
class ScrollAdjust : ReactiveComponent {
    private const int Min = 1;
    private const int Max = 10;

    protected override GameObject Construct() {
        var value = Remember(5);

        return new Layout {
            FlexController = {
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 4.pt
            },

            Children = {
                new Background {
                    FlexController = {
                        FlexDirection = FlexDirection.Column,
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center
                    },

                    FlexItem = {
                        Size = new() { x = 26.pt, y = 20.pt }
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    Color = Color.white with { a = 0.1f },

                    Do = x => x.WithPointerEvents(onScroll: h => {
                        var delta = h.EventData?.scrollDelta.y ?? 0f;

                        if (delta != 0f) {
                            value.Value = Mathf.Clamp(
                                value.Value + (delta > 0f ? 1 : -1),
                                Min,
                                Max
                            );
                        }
                    }),

                    Children = {
                        new Label {
                            FontSize = 8f,
                            sText = value.Map(x => x.ToString())
                        },

                        new Label {
                            Text = "scroll here",
                            FontSize = 2.8f,
                            Color = Color.white with { a = 0.6f }
                        }
                    }
                },

                new Layout {
                    FlexController = {
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center
                    },

                    FlexItem = {
                        Size = (Max * 2.4f).pt
                    },

                    Children = {
                        new Background {
                            FlexItem = {
                                sSize = value.Map(x =>
                                    new YogaVector((x * 2.4f).pt)
                                )
                            },

                            Sprite = BeatSaberResources.Sprites.background,
                            PixelsPerUnit = 10f,
                            sColor = value.Map(x => Color.HSVToRGB(
                                x / (float)Max * 0.8f,
                                0.7f,
                                1f
                            ))
                        }
                    }
                }
            }
        }.Use();
    }
}
```
</Playground>

Each notch moves the number by one, however far the mouse says it scrolled, and the number stops at both ends. Content
that only needs to scroll doesn't need any of this, since a `ScrollArea`, or a `Table` for long lists, handles it for
you. See [Repeaters and Tables](/docs/reactive/lists/lists#tables-and-scrolling).

<Alert>
    In VR there's no mouse wheel, so on its own `onScroll` only works in FPFC. To scroll with the joystick as well, add
    a `VRScrollAdapter` component to the graphic, the same one scroll areas and tables use.
</Alert>
