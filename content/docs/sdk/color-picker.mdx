The color picker follows the input field's shape: a `BsColorPicker` swatch you click, a `BsColorCircleModal` that
opens next to it, and a `BsColorPickerContext` they share. The showcase's *Color picker* page:

<Playground preview="/assets/sdk/color-picker.webp">
```csharp excerpt
var pickerContext = new BsColorPickerContext { SelectedColor = Color.cyan };
var pickerAnchor = Ref<RectTransform>();

new BsColorPicker {
    Context = pickerContext,
    sColors = Palette.Map(ShowcaseStyles.ColorPicker)
}.Bind(pickerAnchor),

new Label {
    sText = pickerContext.Map(x =>
        $"Live: {Format(x.Color)}\n" +
        $"Selected: {Format(x.SelectedColor)}\n" +
        $"Focused: {x.Focused}"
    )
},

new BsColorCircleModal {
    Context = pickerContext,
    PlacementAnchor = pickerAnchor,
    Title = "Pick a color",
    PlacementData = new() {
        Placement = RelativePlacement.RightCenter,
        Offset = new(2f, 0f)
    }
}
```
```csharp
class Picker : ReactiveComponent {
    protected override GameObject Construct() {
        var pickerContext = new BsColorPickerContext {
            SelectedColor = Color.cyan
        };
        var pickerAnchor = Ref<RectTransform>();

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.FlexStart,
                Gap = 2.pt,
                Padding = 4.pt
            },

            Children = {
                new BsColorPicker {
                    Context = pickerContext
                }.Bind(pickerAnchor),

                new Label {
                    FlexItem = {
                        Margin = new() { top = 34.pt }
                    },

                    Alignment = TextAlignmentOptions.Left,
                    sText = pickerContext.Map(x =>
                        $"Live: {Format(x.Color)}\n" +
                        $"Selected: {Format(x.SelectedColor)}\n" +
                        $"Focused: {x.Focused}"
                    )
                },

                new BsColorCircleModal {
                    Context = pickerContext,
                    PlacementAnchor = pickerAnchor,
                    Title = "Pick a color",
                    PlacementData = new() {
                        Placement = RelativePlacement.RightCenter,
                        Offset = new(2f, 0f)
                    }
                }
            }
        }.Use();
    }

    private static string Format(Color c) =>
        $"#{(int)(c.r * 255):X2}{(int)(c.g * 255):X2}{(int)(c.b * 255):X2}";
}
```
</Playground>


The context has two colors. `Color` is live and changes as you drag around the circle. `SelectedColor` is what you
let go on. Bind the live one for a preview and the selected one for the actual setting. `Focused` says whether the
modal is open. `PlacementData` positions the modal relative to the anchor, with a `RelativePlacement` corner or edge
and an offset. `Animated` and `ShowBackground` on the modal are the cosmetic switches, and they apply on the next open.

The circle itself is a component you can use without the modal:

<Playground preview="/assets/sdk/color-circle.webp">
```csharp excerpt
new BsColorCircle {
    FlexItem = {
        Size = 32.pt
    },

    Color = live.Value,
    OnColorUpdated = x => live.Value = x,
    OnColorSaved = x => saved.Value = x
}
```
```csharp
class Circle : ReactiveComponent {
    protected override GameObject Construct() {
        var live = Remember(new Color(1f, 0.45f, 0.2f));
        var saved = Remember(Color.cyan);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 3.pt
            },

            Children = {
                new BsColorCircle {
                    FlexItem = {
                        Size = 32.pt
                    },

                    Color = live.Value,
                    OnColorUpdated = x => live.Value = x,
                    OnColorSaved = x => saved.Value = x
                },

                new Background {
                    FlexItem = {
                        Size = new() { x = 32.pt, y = 4.pt }
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    Color = Color.white,
                    UseGradient = true,
                    GradientDirection = HMUI.ImageView.GradientDirection.Horizontal,
                    sGradientColor0 = live,
                    sGradientColor1 = saved
                }
            }
        }.Use();
    }
}
```
</Playground>


`OnColorUpdated` fires while dragging and `OnColorSaved` on release, matching the two colors on the context.
Setting `Color` from code moves the handle as if the user had picked it.

## Properties

These are `BsColorPicker`'s. `BsColorCircleModal` takes the same `Context`, a `PlacementAnchor`, `PlacementData`, `Title`, `ShowBackground`, `Animated`, `ClickOffCloses` and `CircleSize` (40pt). The standalone `BsColorCircle` has `Color`, a read-only `SavedColor`, `OnColorUpdated` while dragging and `OnColorSaved` on release. Every property with a setter also has an `s`-version that takes a state.
