`Label` is TextMeshPro text as a leaf component, so a label is exactly as big as its text unless you tell it
otherwise. The showcase's *Labels* page goes through what you can do with it.

## Styles

```csharp
new Label { Text = "Bold", FontStyle = FontStyles.Bold },
new Label { Text = "Italic", FontStyle = FontStyles.Italic },
new Label { Text = "Underline", FontStyle = FontStyles.Underline },
new Label { Text = "Strike", FontStyle = FontStyles.Strikethrough },
new Label { Text = "Small caps", FontStyle = FontStyles.SmallCaps },
new Label { Text = "upper", FontStyle = FontStyles.UpperCase }
```

<Screenshot src="/assets/sdk/labels-styles.png" alt="A row of labels in different font styles" />

`FontStyle` is a flags enum, so `FontStyles.Bold | FontStyles.Italic` is both. `FontSize` defaults to 4, `Color` to
white, and `Alignment` to center. A label in a sized box therefore sits in the middle unless you set `TopLeft`.

## Rich text

```csharp
new Label {
    RichText = true,
    FontSize = 4f,
    sText = Palette.Map(x =>
        $"Rich text with <color=#{ColorUtility.ToHtmlStringRGB(x.Primary)}>" +
        $"primary</color>, " +
        "<size=150%>big</size> and <alpha=#66>faded<alpha=#FF> parts"
    )
}
```

<Screenshot src="/assets/sdk/labels-rich.png" alt="One label with colored, enlarged and faded words" />

`RichText` enables TextMeshPro's tags, which is the cheap way to style parts of a line without several labels.
It's off by default because a `<` in user text would otherwise be eaten.

## Wrapping and auto-sizing

A label doesn't wrap by default. It grows to fit its line. `EnableWrapping = true` with a width makes it a paragraph,
and `Overflow = TextOverflowModes.Ellipsis` truncates instead. Auto-sizing fits the text to the box:

<Playground preview="/assets/sdk/labels-autosize.webp">
```csharp excerpt
new Background {
    FlexItem = {
        sSize = width.Map(x => new YogaVector(x.pt, 10.pt))
    },

    FlexController = {
        JustifyContent = Justify.Center,
        AlignItems = Align.Center,
        Padding = 1.pt
    },

    Children = {
        new Label {
            FlexItem = {
                Flex = 1f,
                Size = new() { y = 100.pct }
            },

            Text = "Squeeze me",
            EnableAutoSizing = true,
            FontSizeMin = 1.5f,
            FontSizeMax = 7f,
            EnableWrapping = false
        }
    }
}
```
```csharp
class Squeeze : ReactiveComponent {
    protected override GameObject Construct() {
        var width = RememberAnimated(40f, 400.ms, AnimationCurve.EaseInOutSine);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 4.pt
            },

            Children = {
                new Background {
                    FlexItem = {
                        sSize = width.Map(x => new YogaVector(x.pt, 10.pt))
                    },

                    FlexController = {
                        JustifyContent = Justify.Center,
                        AlignItems = Align.Center,
                        Padding = 1.pt
                    },

                    Sprite = BeatSaberResources.Sprites.background,
                    PixelsPerUnit = 10f,
                    Color = Color.white with { a = 0.12f },

                    Children = {
                        new Label {
                            FlexItem = {
                                Flex = 1f,
                                Size = new() { y = 100.pct }
                            },

                            Text = "Squeeze me",
                            EnableAutoSizing = true,
                            FontSizeMin = 1.5f,
                            FontSizeMax = 7f,
                            EnableWrapping = false
                        }
                    }
                },

                new BsSlider {
                    FlexItem = { Size = new() { x = 50.pt, y = 7.pt } },
                    MinValue = 14f,
                    MaxValue = 40f,
                    ValueStep = 1f,
                    Value = 40f,
                    ValueFormatter = x => $"{x:0} pt",
                    OnValueChanged = x => width.TargetValue = x
                }
            }
        }.Use();
    }
}
```
</Playground>


`EnableAutoSizing` with `FontSizeMin` and `FontSizeMax` picks the largest size that fits. The label takes the box's
width with `Flex = 1` and its height with a percent, because auto-sizing needs a box to fit into. With no size it
would just be its text.

Changing `Text` every frame is fine, by the way. The showcase's typewriter and per-letter rainbow set `Text` from
`OnUpdate`, and the label re-measures only when the frame lays out, so it's one measure per frame however often
you write it.
