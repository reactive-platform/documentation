A modal is content that appears over the current screen, dims what's behind it and goes away when dismissed.
The showcase's *Modals* page has a plain `Modal` and a `Dialog`, and the plain one shows everything:

<Playground preview="/assets/sdk/modal.webp">
```csharp excerpt
var opened = Remember(false);
var anchor = Ref<RectTransform>();

new BsPrimaryTextButton {
    Text = "Open",
    OnClick = () => opened.Value = true
}.Bind(anchor),

new Modal {
    sIsPushed = opened,
    PlacementAnchor = anchor,
    sPlacementData = placement.Map(x => new PlacementData {
        Placement = x,
        Offset = Vector2.zero
    }),
    sCompositionAnimation = composition,
    sOpenAnimation = openAnimation,
    sCloseAnimation = closeAnimation,
    OnClickOutside = () => opened.Value = false,

    Children = {
        new Background {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                Padding = 3.pt,
                Gap = 2.pt
            },

            FlexItem = {
                MinSize = new() { x = 50.pt }
            },

            Children = {
                new Label { Text = "A modal" },

                new BsTextButton {
                    Text = "Close",
                    OnClick = () => opened.Value = false
                }
            }
        }.AsBlurBackground()
    }
}
```
```csharp
class ModalExample : ReactiveComponent {
    protected override GameObject Construct() {
        var opened = Remember(false);
        var anchor = Ref<RectTransform>();

        return new Layout {
            FlexController = {
                AlignItems = Align.Center,
                JustifyContent = Justify.Center
            },

            Children = {
                new BsPrimaryTextButton {
                    Text = "Open",
                    OnClick = () => opened.Value = true
                }.Bind(anchor),

                new Modal {
                    sIsPushed = opened,
                    PlacementAnchor = anchor,
                    PlacementData = new() {
                        Placement = RelativePlacement.RightCenter,
                        Offset = new(2f, 0f)
                    },
                    OnClickOutside = () => opened.Value = false,

                    Children = {
                        new Background {
                            FlexController = {
                                FlexDirection = FlexDirection.Column,
                                AlignItems = Align.Center,
                                Padding = 3.pt,
                                Gap = 2.pt
                            },

                            FlexItem = {
                                MinSize = new() { x = 50.pt }
                            },

                            Children = {
                                new Label { Text = "A modal" },

                                new BsTextButton {
                                    Text = "Close",
                                    OnClick = () => opened.Value = false
                                }
                            }
                        }.AsBlurBackground()
                    }
                }
            }
        }.Use();
    }
}
```
</Playground>


Opening and closing is one `bool`: `IsPushed`, bound here as `sIsPushed = opened`. The open button sets it, the
close button clears it, and `OnClickOutside` clears it too, since clicking the dimmed area doesn't close anything
on its own. There is no `Open()` or `Close()` method. It is a state like everything else, so anything can open the
modal by writing it.

The modal's content is a bare layout. The example therefore wraps its children in a `Background` and calls
`.AsBlurBackground()` on it: that's the frosted panel look, and it's your choice to apply it. The content fits
itself, as a root layout with its constraints off would, and `MinSize` keeps it from being narrower than its title.

## Placement

`PlacementAnchor` is a `Ref<RectTransform>` that some component fills in with `.Bind(anchor)`, usually the button
that opens the modal. `PlacementData` then says where to put the modal relative to it: a `RelativePlacement` such
as `RightCenter` or `BottomLeft`, an `Offset`, and `Clip`, which moves the modal back inside the screen when it would
hang off the edge. Without an anchor the modal is centered.

## Animations

The open and close animations are ordinary `Animation<IReactiveComponent>`s from [Animation Players and Tracks](/docs/reactive/animation/players),
played on the modal's content. The defaults, `ModalAnimations.JumpOpen` and `JumpClose`, stretch the modal out of a
line the way the game does. The showcase swaps them for a zoom:

```csharp
new(
    Track: AnimationTracks.Fade(0f, 1f) + AnimationTracks.Scale(0.4f, 1f),
    Duration: 350.ms,
    Curve: AnimationCurve.EaseOutBack
),
new(
    Track: AnimationTracks.Fade(1f, 0f) + AnimationTracks.Scale(1f, 0.4f),
    Duration: 200.ms,
    Curve: AnimationCurve.EaseInBack
)
```

Each custom pair resets both alpha and scale, because whichever close animation ran last might have left either
one off. `CompositionAnimation` is a `CompositionAnimParams` for the screen behind: `DimCanvas`, `DimmedAlpha`,
`Duration` and `Curve`. And `Animated = false` turns all of it off for a modal that should just appear.

## How overlays work

A modal is declared wherever is convenient, usually next to its trigger, and it isn't visible there. When pushed,
it finds the nearest `Composition` up the hierarchy, which the plugin puts on every `ViewController` as it activates,
reparents itself to the top of that, stretches to cover it, dims it, and sits above everything by `ZIndex`. When popped, it goes back to
where it was declared. This is `Overlay`, and `Modal` is an overlay with a blocker that catches clicks outside and
the placement and animation on top. You can push an `Overlay` yourself for something that isn't modal-shaped,
a toast layer say.

## Dialogs

`Dialog` is a modal with a header, a content area and OK and Cancel buttons:

<Playground preview="/assets/sdk/dialog.webp">
```csharp excerpt
new Dialog {
    Title = "Careful",
    sIsPushed = dialogOpened,
    PlacementAnchor = dialogAnchor,
    OnClickOutside = () => dialogOpened.Value = false,

    FlexController = {
        Padding = 3.pt
    },

    Children = {
        new Label {
            Text = "This would delete everything.",
            FontSize = 3.5f
        }
    }
}.With(x => {
    x.OkButton.OnClick = () => {
        Delete();
        dialogOpened.Value = false;
    };

    x.CancelButton.OnClick = () => dialogOpened.Value = false;
})
```
```csharp
class DialogExample : ReactiveComponent {
    protected override GameObject Construct() {
        var dialogOpened = Remember(false);
        var dialogAnchor = Ref<RectTransform>();

        return new Layout {
            FlexController = {
                AlignItems = Align.Center,
                JustifyContent = Justify.Center
            },

            Children = {
                new BsPrimaryTextButton {
                    Text = "Delete",
                    OnClick = () => dialogOpened.Value = true
                }.Bind(dialogAnchor),

                new Dialog {
                    Title = "Careful",
                    sIsPushed = dialogOpened,
                    PlacementAnchor = dialogAnchor,
                    OnClickOutside = () => dialogOpened.Value = false,

                    FlexController = {
                        Padding = 3.pt
                    },

                    Children = {
                        new Label {
                            Text = "This would delete everything.",
                            FontSize = 3.5f
                        }
                    }
                }.With(x => {
                    x.OkButton.OnClick = () => {
                        Delete();
                        dialogOpened.Value = false;
                    };

                    x.CancelButton.OnClick = () => dialogOpened.Value = false;
                })
            }
        }.Use();
    }

    private static void Delete() { }
}
```
</Playground>


Neither button closes the dialog by itself. You wire `OkButton.OnClick` and `CancelButton.OnClick`, which is also
where the actual action goes. The blurred background and the header styling are built in.

## Shared modals

The dropdown list, the keyboard, the numpad and the color circle are all `SharedModal<T>`: a stand-in that sits in
the hierarchy like a modal, and when pushed borrows an actual modal of type `T` from the [global pool](/docs/reactive/lists/pooling#globalreactivepool),
applies `ApplyProps` to it and pushes that. When it closes, the modal goes back to the pool. So a mod with a
dropdown on every screen builds one list, and `ApplyProps` is where everything the modal needs gets set each time,
since the modal is reset when returned. Any modal of yours that implements `IPoolableComponent` can be shared the same way.
## Properties

These are `Modal`'s, and everything but the last two is `ModalBase` and so shared by every modal. `Dialog` adds `Title`, an `OkButton` and a `CancelButton` to wire yourself. `SharedModal<T>` has `IsPushed`, `ApplyProps` and a read-only `Modal`. Every property with a setter also has an `s`-version that takes a state.
