`BsListControl<TKey>` is the game's left-arrow, value, right-arrow control. The showcase's *List control* page:

<Playground preview="/assets/sdk/list-control.webp">
```csharp excerpt
new BsListControl<string> {
    sColors = colors,
    sInteractable = interactable,
    Items = difficultyItems,
    Key = "Expert"
},

new BsListControl<int> {
    sColors = colors,
    sInteractable = interactable,
    Items = [
        new(0, "Edit", GameResources.EditIcon),
        new(1, "Search", GameResources.SearchIcon),
        new(2, "Close", GameResources.CloseIcon)
    ],
    Key = 0
},

new BsListControl<string> {
    sColors = colors,
    Skew = 0f,
    Items = difficultyItems,
    Key = "Normal"
}
```
```csharp
class ListControls : ReactiveComponent {
    protected override GameObject Construct() {
        var difficultyItems = new BsListControlItem<string>[] {
            new("Easy", "Easy", null),
            new("Normal", "Normal", null),
            new("Hard", "Hard", null),
            new("Expert", "Expert", null),
            new("Expert+", "Expert+", null)
        };

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 2.pt
            },

            Children = {
                new BsListControl<string> {
                    FlexItem = { Size = new() { x = 50.pt, y = 7.pt } },
                    Items = difficultyItems,
                    Key = "Expert"
                },

                new BsListControl<int> {
                    FlexItem = { Size = new() { x = 50.pt, y = 7.pt } },
                    Items = [
                        new(0, "Edit", GameResources.EditIcon),
                        new(1, "Search", GameResources.SearchIcon),
                        new(2, "Close", GameResources.CloseIcon)
                    ],
                    Key = 0
                },

                new BsListControl<string> {
                    FlexItem = { Size = new() { x = 50.pt, y = 7.pt } },
                    Skew = 0f,
                    Items = difficultyItems,
                    Key = "Normal"
                }
            }
        }.Use();
    }
}
```
</Playground>


Unlike the dropdown and segmented control, `Items` is an ordered list of `BsListControlItem<T>(key, text, icon)`,
because order is what the arrows step through. The left arrow disables at the first item and the right one at the
last. It doesn't wrap around. `Key` is the current item, `OnKeyChanged` fires when it changes, including when you set
`Key` from code, which the showcase uses to step a control automatically from `OnUpdate`.

If the items change and the current key is still among them, the control stays on it. Otherwise it resets to the
first one. The content color follows the key in the showcase's last example by deriving `sColors` from the key
state, which is a nice reminder that `Colors` is just a value you can compute.
