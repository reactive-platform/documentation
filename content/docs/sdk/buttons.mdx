The plain game button is a background that lights up on hover, with an underline. There's a text version, an image
version, and the base one that takes whatever content you give it. The showcase's *Buttons* page lines up the variants:

<Playground preview="/assets/sdk/buttons.webp">
```csharp excerpt
new BsTextButton { Text = "Stock" },
new BsTextButton { Text = "Themed", sColors = colors },
new BsTextButton { Text = "Plain", ShowUnderline = false, sColors = colors },
new BsTextButton { Text = "Straight", Skew = 0f, sColors = colors },
new BsTextButton {
    Text = "Maybe",
    sInteractable = interactable,
    sColors = colors
},

new BsImageButton {
    FlexItem = {
        Size = 8.pt
    },

    Sprite = GameResources.EditIcon,
    sInteractable = interactable,
    sColors = colors
}
```
```csharp
class Buttons : ReactiveComponent {
    protected override GameObject Construct() {
        var interactable = Remember(false);

        return new Layout {
            FlexController = {
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 2.pt
            },

            Children = {
                new BsTextButton { Text = "Stock" },
                new BsTextButton { Text = "Plain", ShowUnderline = false },
                new BsTextButton { Text = "Straight", Skew = 0f },
                new BsTextButton {
                    Text = "Maybe",
                    sInteractable = interactable
                },

                new BsImageButton {
                    FlexItem = {
                        Size = 8.pt
                    },

                    Sprite = GameResources.EditIcon,
                    sInteractable = interactable
                }
            }
        }.Use();
    }
}
```
</Playground>


`OnClick` is the one property every button has, and the one the snippet above leaves out. `Text` on the text button
forwards to a label, and its font properties are reachable through the same label. `Interactable` greys the button
out through the `NotInteractable` colors of its color sets and stops it reacting. `ShowUnderline` and `Skew` are the
two cosmetic switches.

## Your own content

`BsButton` is the base: the background, the hover and press behaviour, and a `ConstructContent` that builds what's
inside. The content function gets two states, the current content color and the current skew, so whatever you put
in can follow them:

<Playground preview="/assets/sdk/button-content.webp">
```csharp excerpt
new BsButton {
    FlexController = {
        Padding = new() { left = 2.pt, right = 2.pt },
        AlignItems = Align.Center,
        Gap = 1.pt
    },

    sColors = colors,
    OnClick = () => clicks.Value++,

    ConstructContent = (color, skew) => new Layout {
        FlexController = {
            AlignItems = Align.Center,
            Gap = 1.pt
        },

        Children = {
            new Image {
                FlexItem = {
                    Size = 4.pt
                },

                Sprite = GameResources.ArrowUpIcon,
                PreserveAspect = true,
                sColor = color.In(),
                sSkew = skew.In()
            },

            new Label {
                sText = clicks.Map(x => $"Clicked {x} times"),
                sColor = color.In()
            }
        }
    }
}
```
```csharp
class CounterButton : ReactiveComponent {
    protected override GameObject Construct() {
        var clicks = Remember(0);

        return new Layout {
            FlexController = {
                AlignItems = Align.Center,
                JustifyContent = Justify.Center
            },

            Children = {
                new BsButton {
                    FlexController = {
                        Padding = new() { left = 2.pt, right = 2.pt },
                        AlignItems = Align.Center,
                        Gap = 1.pt
                    },

                    OnClick = () => clicks.Value++,

                    ConstructContent = (color, skew) => new Layout {
                        FlexController = {
                            AlignItems = Align.Center,
                            Gap = 1.pt
                        },

                        Children = {
                            new Image {
                                FlexItem = {
                                    Size = 4.pt
                                },

                                Sprite = GameResources.ArrowUpIcon,
                                PreserveAspect = true,
                                sColor = color.In(),
                                sSkew = skew.In()
                            },

                            new Label {
                                sText = clicks.Map(x => $"Clicked {x} times"),
                                sColor = color.In()
                            }
                        }
                    }
                }
            }
        }.Use();
    }
}
```
</Playground>


The `.In()` on `color` and `skew` is the thing from [Bindings](/docs/reactive/state/states): they
arrive as `IState<T>`, so they need it. The button is also a layout controller holder, so `FlexController`
works on it and the padding and gap apply to your content.

`BsTextButton` and `BsImageButton` are exactly this with a label or an image as the content, so once you've written
one `ConstructContent` you know what they are.
## Properties

These are `BsTextButton`'s. `BsImageButton` swaps the label properties for `Sprite`, `Material`, `PreserveAspect`, `ImageType`, `FillMethod`, `FillAmount` and `PixelsPerUnit`. `BsButton` itself has only the last five rows plus `ConstructContent`, a required init-only `(IState<Color> color, IState<float> skew) => ILayoutItem`, and a `LayoutController`. Every property with a setter also has an `s`-version that takes a state.
