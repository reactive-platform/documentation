## A different tree

Flexbox covers most screens, but some layouts don't fit it, like a ring of buttons, a radial menu or a grid with its own
packing rules. For those you can write your own controller, and a container that uses it places its children by your
rules instead.

Your controller doesn't replace the flexbox around it, but works alongside it. Nested flex layouts share one Yoga tree,
and your controller can't join that tree, so it starts a tree of its own. To the flex layout around it, that whole tree
looks like a single leaf, the same as a label. The parent measures it when its size isn't fixed, and the tree then lays
out its children inside the box it gets.

Here's an example with both kinds of tree side by side. On the left, three flex layouts are stitched into one tree, and
on the right, a ring uses a `RadialLayoutController` and is sized by its flex parent as one box:

class RadialDemo : ReactiveComponent {
    private const int ItemCount = 8;

        var radius = Remember(10f);

                    MaxValue = 11f,

                    ValueFormatter = x => $"radius {x:0}",

                    FlexController = {
                        AlignItems = Align.FlexStart,
                        Gap = 4.pt

                                },

```csharp title="RadialLayoutController.cs"
class RadialLayoutController : ILayoutController {
    public float Radius {
        get => _radius;
        set {
            _radius = value;
            LayoutControllerUpdatedEvent?.Invoke();
        }
    }

    public int ChildCount => _children.Count;

    public event Action? LayoutControllerUpdatedEvent;

    private readonly List<ILayoutItem> _children = new();
    private readonly List<LayoutDimensions> _dimensions = new();
    private float _radius = 10f;
    private Vector2 _size;

    // No context type, so a parent never stitches this controller into its
    // tree and measures it instead
    public Type? ContextType => null;
    public object CreateContext() => new object();
    public void ProvideContext(object? context) { }

    public void InsertChild(ILayoutItem child, int index) {
        _children.Insert(index, child);
        LayoutControllerUpdatedEvent?.Invoke();
    }

    public void RemoveChild(ILayoutItem child) {
        _children.RemoveAll(x => x.EqualsToLayoutItem(child));
        LayoutControllerUpdatedEvent?.Invoke();
    }

    public void RemoveAllChildren() {
        _children.Clear();
        LayoutControllerUpdatedEvent?.Invoke();
    }

    public bool HasChild(ILayoutItem child) => _children.Exists(
        x => x.EqualsToLayoutItem(child)
    );
    public void UpdateChild(ILayoutItem item) { }
    public void UpdateSelf(ILayoutItem item) { }

    public void Recalculate(Vector2 constraints) {
        _dimensions.Clear();

        var centers = new Vector2[_children.Count];
        var sizes = new Vector2[_children.Count];
        var min = Vector2.zero;
        var max = Vector2.zero;

        // Place the children around a center at zero and track the box they fill
        for (var i = 0; i < _children.Count; i++) {
            sizes[i] = _children[i].Measure(
                width: float.NaN,
                widthMode: MeasureMode.Undefined,
                height: float.NaN,
                heightMode: MeasureMode.Undefined
            );

            var turn = i / (float)_children.Count;
            var angle = turn * Mathf.PI * 2f - Mathf.PI / 2f;
            var direction = new Vector2(Mathf.Cos(angle), Mathf.Sin(angle));
            centers[i] = direction * _radius;

            var from = centers[i] - sizes[i] / 2f;
            var to = centers[i] + sizes[i] / 2f;

            if (i == 0) {
                min = from;
                max = to;
            } else {
                min = new Vector2(Mathf.Min(min.x, from.x), Mathf.Min(min.y, from.y));
                max = new Vector2(Mathf.Max(max.x, to.x), Mathf.Max(max.y, to.y));
            }
        }

        var bounds = max - min;
        _size = constraints.x > 0f && constraints.y > 0f
            ? constraints
            : bounds;

        // Center the children's box inside the box this controller is given
        var shift = (_size - bounds) / 2f - min;

        for (var i = 0; i < _children.Count; i++) {
            var corner = centers[i] - sizes[i] / 2f + shift;

            _dimensions.Add(new LayoutDimensions(
                TopOffset: corner.y,
                LeftOffset: corner.x,
                Width: sizes[i].x,
                Height: sizes[i].y
            ));
        }
    }

    public LayoutDimensions GetSelfDimensions() {
        return new LayoutDimensions(0f, 0f, _size.x, _size.y);
    }

    public LayoutDimensions GetChildDimensions(ILayoutItem child) {
        var index = _children.FindIndex(x => x.EqualsToLayoutItem(child));
        return index >= 0 && index < _dimensions.Count
            ? _dimensions[index]
            : default;
    }

    // How the flex parent asks this tree for its size when it isn't fixed
    public Vector2 Measure(
        float width,
        MeasureMode widthMode,
        float height,
        MeasureMode heightMode
    ) {
        Recalculate(Vector2.zero);
        return LayoutTool.MeasureNode(
            preferredSize: _size,
            width: width,
            widthMode: widthMode,
            height: height,
            heightMode: heightMode
        );
    }
}
```

## The controller

A controller implements `ILayoutController`. Below you can see the radial controller in full, which places
its children on a circle around the center of whatever box it's given:

```csharp
class RadialLayoutController : ILayoutController {
    public float Radius {
        get => _radius;
        set {
            _radius = value;
            LayoutControllerUpdatedEvent?.Invoke();
        }
    }

    public int ChildCount => _children.Count;

    public event Action? LayoutControllerUpdatedEvent;

    private readonly List<ILayoutItem> _children = new();
    private readonly List<LayoutDimensions> _dimensions = new();
    private float _radius = 10f;
    private Vector2 _size;

    // No context type, so a parent never stitches this controller into its
    // tree and measures it instead
    public Type? ContextType => null;
    public object CreateContext() => new object();
    public void ProvideContext(object? context) { }

    public void InsertChild(ILayoutItem child, int index) {
        _children.Insert(index, child);
        LayoutControllerUpdatedEvent?.Invoke();
    }

    public void RemoveChild(ILayoutItem child) {
        _children.RemoveAll(x => x.EqualsToLayoutItem(child));
        LayoutControllerUpdatedEvent?.Invoke();

    public void RemoveAllChildren() {
        _children.Clear();

    }

        x => x.EqualsToLayoutItem(child)

    public void UpdateChild(ILayoutItem item) { }
    public void UpdateSelf(ILayoutItem item) { }

        _dimensions.Clear();

        var sizes = new Vector2[_children.Count];
        var min = Vector2.zero;
        var max = Vector2.zero;

            height: height,
            heightMode: heightMode

```

A controller has a few jobs, and its members are grouped by them:

- **Computing the layout:** `Recalculate` measures the children and decides their dimensions and its own size, without
  applying anything. The container then reads the results through `GetSelfDimensions` and `GetChildDimensions`.
- **Being measured:** a flex parent calls `Measure` when this tree's size isn't fixed.
- **Tracking children:** `InsertChild`, `RemoveChild` and the other child members are bookkeeping. Compare items with
  `EqualsToLayoutItem` rather than by reference, because a component and its host count as the same item.
- **Asking for a recalculation:** raise `LayoutControllerUpdatedEvent` whenever a property changes the result or
  children come and go, and the container schedules a new layout.
- **Applying its own modifier:** `UpdateSelf` does this when the container is a root, which the radial controller doesn't
  need.
- **Stitching:** a `ContextType` of `null` means a parent never stitches this controller into its tree and measures it
  instead. [Layout Engine Internals](/docs/reactive/under-the-hood/layout#stitching) explains how to make controllers of
  your own kind stitch, the way flex controllers do.

Put together, these pieces are all a controller needs, so the radial one above works as a template for your own. Replace
the circle math in `Recalculate` with your own placement rules, keep the bookkeeping and the update event as they are,
and the container takes care of applying the result.

## Inside flexbox

The first example gives the ring a fixed `Size`, so its parent never needs to measure it. Without one, the parent calls
the controller's `Measure`, and the radial controller answers with the size of the box its children fill. The row is
laid out with that size, and then the ring places its numbers inside the box it ends up with.

`Measure` gets a width and a height from the parent, each with a measure mode that says how to treat it. With
`Undefined` the value means nothing and the parent wants the natural size, with `Exactly` the tree must be that size,
and with `AtMost` it can be up to that size. Most controllers only work out their preferred size and pass it
to `LayoutTool.MeasureNode`, which picks the right answer for each mode.

The radial controller does exactly that, recalculating without constraints and handing the size it got to the helper:

```csharp
public Vector2 Measure(
    float width,
    MeasureMode widthMode,
    float height,
    MeasureMode heightMode
) {
    // With no constraints, Recalculate sizes the controller to its children
    Recalculate(Vector2.zero);

    return LayoutTool.MeasureNode(
        preferredSize: _size,
        width: width,
        widthMode: widthMode,
        height: height,
        heightMode: heightMode
    );
}
```

`Measure` should only calculate and never apply anything, because the parent may call it several times with different
constraints before it settles, and the container recalculates with the final box afterwards anyway. A controller that
adapts to the space it's offered, like a grid that adds rows when its width is `AtMost`, reads the width and its mode
itself instead of only reporting a preferred size.

class RingsInRow : ReactiveComponent {
    private static readonly (float radius, int items)[] Rings = {
        (5f, 3),
        (8f, 6),
        (11f, 8)
    };

    private Layout _rings = null!;
    private readonly List<Background> _added = new();

    protected override GameObject Construct() {
        var row = new Layout {
            FlexController = {
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 3.pt
            },

            Children = {
                CreateBlock(new Color(0f, 0.75f, 1f)),

                new Layout {
                    FlexController = {
                        AlignItems = Align.Center,
                        Gap = 3.pt
                    }
                }.Bind(ref _rings),

                CreateBlock(new Color(1f, 0.2f, 0.8f))
            }
        };

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 4.pt
            },

            Children = {
                row,

                new Layout {
                    FlexController = {
                        Gap = 2.pt
                    },

                    Children = {
                        new BsTextButton {
                            Text = "Add a ring",
                            OnClick = AddRing
                        },
                        new BsTextButton {
                            Text = "Remove",
                            OnClick = RemoveRing
                        }
                    }
                }
            }
        }.Use();
    }

    private void AddRing() {
        if (_added.Count == Rings.Length) return;

        var (radius, items) = Rings[_added.Count];

        // No size of its own: the row measures the ring through its controller
        var ring = new Background {
            LayoutController = new RadialLayoutController { Radius = radius },

            Sprite = BeatSaberResources.Sprites.background,
            PixelsPerUnit = 10f,
            Color = Color.white with { a = 0.1f }
        };

        for (var i = 0; i < items; i++) {
            ring.Children.Add(new Label {
                Text = (i + 1).ToString(),
                FontSize = 4f,
                Color = Color.HSVToRGB(i / (float)items, 0.6f, 1f)
            });
        }

        _added.Add(ring);
        _rings.Children.Add(ring);
    }

    private void RemoveRing() {
        if (_added.Count == 0) return;

        var last = _added[^1];
        _added.RemoveAt(_added.Count - 1);
        _rings.Children.Remove(last);
        last.Destroy();
    }

    private static Background CreateBlock(Color color) {
        return new Background {
            FlexItem = {
                Size = 12.pt
            },

            Sprite = BeatSaberResources.Sprites.background,
            PixelsPerUnit = 10f,
            Color = color
        };
    }
}

## Flexbox inside

We've seen that a flex row used `Measure` to fit a ring in, and this works the same way in reverse. A custom
controller can hold flex layouts as children, each one a Yoga tree of its own, and it measures them like it measures a
label. Calling `Measure` on a `Layout` asks its flex controller to calculate the subtree and report the size.

In this example the ring holds flex cards, and a toggle makes two of them grow:

class CardsOnRing : ReactiveComponent {
    private const int ItemCount = 5;

    protected override GameObject Construct() {
        var expanded = Remember(false);

        var ring = new Layout {
            LayoutController = new RadialLayoutController { Radius = 14f },

            FlexItem = {
                Size = 46.pt
            }
        };

        for (var i = 0; i < ItemCount; i++) {
            ring.Children.Add(CreateCard(
                index: i,
                expanded: expanded

            FlexController = {

                a = 0.6f
            },

            Children = {
                new Label {
                    Text = (index + 1).ToString(),
                    FontSize = 3.6f,
                    Color = Color.HSVToRGB(index / (float)ItemCount, 0.6f, 1f)
                },

                new Label {

class RadialLayoutController : ILayoutController {
    public float Radius {
        get => _radius;
        set {
            _radius = value;
            LayoutControllerUpdatedEvent?.Invoke();
        }
    }

    public int ChildCount => _children.Count;

    public event Action? LayoutControllerUpdatedEvent;

    private readonly List<ILayoutItem> _children = new();
    private readonly List<LayoutDimensions> _dimensions = new();
    private float _radius = 10f;
    private Vector2 _size;

    // No context type, so a parent never stitches this controller into its
    // tree and measures it instead
    public Type? ContextType => null;
    public object CreateContext() => new object();
    public void ProvideContext(object? context) { }

    public void InsertChild(ILayoutItem child, int index) {
        _children.Insert(index, child);
        LayoutControllerUpdatedEvent?.Invoke();
    }

    public void RemoveChild(ILayoutItem child) {
        _children.RemoveAll(x => x.EqualsToLayoutItem(child));
        LayoutControllerUpdatedEvent?.Invoke();
    }

    public void RemoveAllChildren() {
        _children.Clear();
        LayoutControllerUpdatedEvent?.Invoke();
    }

    public bool HasChild(ILayoutItem child) => _children.Exists(
        x => x.EqualsToLayoutItem(child)
    );
    public void UpdateChild(ILayoutItem item) { }
    public void UpdateSelf(ILayoutItem item) { }

    public void Recalculate(Vector2 constraints) {
        _dimensions.Clear();

        var centers = new Vector2[_children.Count];
        var sizes = new Vector2[_children.Count];
        var min = Vector2.zero;
        var max = Vector2.zero;

        // Place the children around a center at zero and track the box they fill
        for (var i = 0; i < _children.Count; i++) {
            sizes[i] = _children[i].Measure(
                width: float.NaN,
                widthMode: MeasureMode.Undefined,
                height: float.NaN,
                heightMode: MeasureMode.Undefined
            );

            var turn = i / (float)_children.Count;
            var angle = turn * Mathf.PI * 2f - Mathf.PI / 2f;
            var direction = new Vector2(Mathf.Cos(angle), Mathf.Sin(angle));
            centers[i] = direction * _radius;

            var from = centers[i] - sizes[i] / 2f;
            var to = centers[i] + sizes[i] / 2f;

            if (i == 0) {
                min = from;
                max = to;
            } else {
                min = new Vector2(Mathf.Min(min.x, from.x), Mathf.Min(min.y, from.y));
                max = new Vector2(Mathf.Max(max.x, to.x), Mathf.Max(max.y, to.y));
            }
        }

        var bounds = max - min;
        _size = constraints.x > 0f && constraints.y > 0f
            ? constraints
            : bounds;

        // Center the children's box inside the box this controller is given
        var shift = (_size - bounds) / 2f - min;

        for (var i = 0; i < _children.Count; i++) {
            var corner = centers[i] - sizes[i] / 2f + shift;

            _dimensions.Add(new LayoutDimensions(
                TopOffset: corner.y,
                LeftOffset: corner.x,
                Width: sizes[i].x,
                Height: sizes[i].y
            ));
        }
    }

    public LayoutDimensions GetSelfDimensions() {
        return new LayoutDimensions(0f, 0f, _size.x, _size.y);
    }

    public LayoutDimensions GetChildDimensions(ILayoutItem child) {
        var index = _children.FindIndex(x => x.EqualsToLayoutItem(child));
        return index >= 0 && index < _dimensions.Count
            ? _dimensions[index]
            : default;
    }

    // How the flex parent asks this tree for its size when it isn't fixed
    public Vector2 Measure(
        float width,
        MeasureMode widthMode,
        float height,
        MeasureMode heightMode
    ) {
        Recalculate(Vector2.zero);
        return LayoutTool.MeasureNode(
            preferredSize: _size,
            width: width,
            widthMode: widthMode,
            height: height,
            heightMode: heightMode
        );
    }
}

Each card is a column that sizes itself to its labels. Flip the toggle and one caption gets longer while another card
shows an extra row, so those cards' trees change and the recalculation they schedule reaches the ring. The ring measures
the cards again and centers each one on the same point of the circle. The card doesn't know it's on a ring, and the ring
doesn't know the card is a column, since each side only measures and places.

Either direction costs an extra pass at the boundary, a measure followed by a recalculation with the final size. That's
nothing for a ring of eight and noticeable for a tree of a thousand, so nest flex in flex where you can and keep
separate trees for the places that need another algorithm.

## Per-child properties

A controller often needs a setting for each child, like an offset that moves it away from its spot. Flexbox keeps those on the
child's modifier, the object behind `FlexItem`, and your controller can do the same with a class of its own. A modifier
implements `ILayoutModifier`, which only asks for a `ModifierUpdatedEvent` that you raise whenever a property changes.

The controller reads it from `child.LayoutModifier` while it recalculates, and falls back to a default when a child has
none or has another kind. Each item holds a single modifier, so a child of the ring uses yours instead of `FlexItem`.
When the event fires, the container calls `UpdateChild` and schedules a recalculation, so the controller doesn't have to
subscribe to anything.

This demo builds on the cards from the previous section, and a slider sets the `Offset` of cards 1, 3 and 4 through
a `RadialModifier`:
