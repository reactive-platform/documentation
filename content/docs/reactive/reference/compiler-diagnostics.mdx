---
title: "Compiler Diagnostics"
description: Every warning and error Reactive.Compiler reports, and what to do about it.
---

The Reactive compiler runs inside the C# compiler and reports these as build diagnostics. The ids are grouped by
feature: `RV0xx` for state bindings, `RV1xx` for required properties and `RV2xx` for component design.
[Compiler Internals](/docs/reactive/under-the-hood/compiler) explains what it generates, and this page is
only the messages.

| Id | Message | Fix |
| --- | --- | --- |
| `RV001` | Incomplete pattern | A `[StateGen(Patterns = ...)]` entry has no rule. Every pattern needs a `{}` and an identifier around it, like `s{}` or `state_{}`. |
| `RV002` | Invalid pattern | Same as above, but the pattern has the wrong shape. |
| `RV021` | Property is a raw state | Informational. A `[RawState]` property receives the state object itself, so binding and unbinding it is your job. |
| `RV022` | Raw states must be `IState<T>` | A `[RawState]` property has to be typed as `IState<T>` (or a type implementing it). |
| `RV041` | Generated binding used outside its generation context | An s-property is used somewhere that doesn't generate it, so it only exists because another usage did. Assign the state inside an object initializer in a `[StateGen]` member instead. |
| `RV061` | State is captured instead of being passed as a dependency | A lambda given to `RememberDerived` (or another `[NoStateCapture]` parameter) reads a state from outside. Add the state to the argument list and take it as a parameter, or the result won't follow it. |
| `RV102` | Required property must be initialized | An object initializer is missing a `[Required]` property. Set it, or bind its s-version, which counts. |
| `RV103` | Shadowed property doesn't exist | `[SetsRequired(Names = [...])]` names a property the target type doesn't have. |
| `RV104` | Property is required and sets required members | A property can be one or the other, not both. |
| `RV105` | Static property cannot be required | Remove `[Required]` from the static property. |
| `RV106` | Property in a static class cannot be required | Same. |
| `RV107` | Required properties must be initialized in a public parameterless constructor | A type with `[Required]` properties needs a public parameterless constructor, which the generator adds unless you declared a different one. Remove yours or make it parameterless and public. |
| `RV201` | Reactive component exposes a public method | A method can't be set in an initializer or bound to a state. Expose its effect as a property whose setter does the work. Static methods, overrides and interface members are left alone. |
| `RV202` | Reactive component exposes a public event | An event can't be set in an initializer either. Declare it as a delegate property instead, like `OnClick`. |
