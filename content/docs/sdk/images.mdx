`Image` draws a sprite and is a leaf. `Background` draws a sprite behind its children and is a container. They share
the drawing properties, and the showcase's *Images* page goes through them.

## Gradients

<Playground preview="/assets/sdk/gradient.gif">
```csharp excerpt
new Background {
    FlexItem = {
        Size = new() { x = 24.pt, y = 12.pt }
    },

    Sprite = BeatSaberResources.Sprites.background,
    PixelsPerUnit = 8f,
    Color = Color.white,
    UseGradient = true,
    sGradientDirection = direction,
    sGradientColor0 = from,
    sGradientColor1 = to
}
```
```csharp
class Gradients : ReactiveComponent {
    private static readonly Color Primary = new(0.35f, 0.75f, 1f);
    private static readonly Color Secondary = new(1f, 0.55f, 0.75f);

    private AnimatedState<Color> _from = null!;
    private AnimatedState<Color> _to = null!;

    protected override GameObject Construct() {
        _from = RememberAnimated(Primary, 900.ms, AnimationCurve.EaseInOutSine);
        _to = RememberAnimated(Secondary, 900.ms, AnimationCurve.EaseInOutSine);

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 4.pt
            },

            Children = {
                new Layout {
                    FlexController = {
                        Gap = 4.pt
                    },

                    Children = {
                        CreateBox(HMUI.ImageView.GradientDirection.Horizontal),
                        CreateBox(HMUI.ImageView.GradientDirection.Vertical)
                    }
                },

                new BsTextButton {
                    Text = "Swap",
                    OnClick = () => (_from.TargetValue, _to.TargetValue) =
                        (_to.TargetValue, _from.TargetValue)
                }
            }
        }.Use();
    }

    [StateGen]
    private Background CreateBox(HMUI.ImageView.GradientDirection direction) {
        return new Background {
            FlexItem = {
                Size = new() { x = 24.pt, y = 12.pt }
            },

            Sprite = BeatSaberResources.Sprites.background,
            PixelsPerUnit = 8f,
            Color = Color.white,
            UseGradient = true,
            GradientDirection = direction,
            sGradientColor0 = _from,
            sGradientColor1 = _to
        };
    }
}
```
</Playground>


`UseGradient` switches it on, `GradientDirection` is horizontal or vertical, and the two gradient colors are the
ends. `Color` still tints the whole thing on top, so the example sets it to white.

## Fills

<Playground preview="/assets/sdk/fills.gif">
```csharp excerpt
new Image {
    FlexItem = {
        Size = 10.pt
    },

    Sprite = GameResources.CircleIcon,
    ImageType = UImage.Type.Filled,
    FillMethod = UImage.FillMethod.Radial360,
    sFillAmount = fill,
    sColor = Palette.Map(x => x.Primary)
}
```
```csharp
class Fills : ReactiveComponent {
    private static readonly Color Primary = new(0.35f, 0.75f, 1f);

    protected override GameObject Construct() {
        var fill = RememberAnimated(
            0.65f,
            900.ms,
            AnimationCurve.EaseInOutSine
        );

        return new Layout {
            FlexController = {
                FlexDirection = FlexDirection.Column,
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 4.pt
            },

            Children = {
                new Layout {
                    FlexController = {
                        AlignItems = Align.Center,
                        Gap = 4.pt
                    },

                    Children = {
                        new Image {
                            FlexItem = { Size = 10.pt },
                            Sprite = GameResources.CircleIcon,
                            ImageType = UnityEngine.UI.Image.Type.Filled,
                            FillMethod = UnityEngine.UI.Image.FillMethod.Radial360,
                            sFillAmount = fill,
                            Color = Primary
                        },

                        new Image {
                            FlexItem = { Size = new() { x = 24.pt, y = 6.pt } },
                            Sprite = BeatSaberResources.Sprites.background,
                            PixelsPerUnit = 10f,
                            ImageType = UnityEngine.UI.Image.Type.Filled,
                            FillMethod = UnityEngine.UI.Image.FillMethod.Horizontal,
                            sFillAmount = fill,
                            Color = Primary
                        },

                        new Image {
                            FlexItem = { Size = new() { x = 6.pt, y = 14.pt } },
                            Sprite = BeatSaberResources.Sprites.background,
                            PixelsPerUnit = 10f,
                            ImageType = UnityEngine.UI.Image.Type.Filled,
                            FillMethod = UnityEngine.UI.Image.FillMethod.Vertical,
                            sFillAmount = fill,
                            Color = Primary
                        }
                    }
                },

                new BsSlider {
                    FlexItem = { Size = new() { x = 50.pt, y = 7.pt } },
                    ValueStep = 0.05f,
                    Value = fill.TargetValue,
                    OnValueChanged = x => fill.TargetValue = x
                }
            }
        }.Use();
    }
}
```
</Playground>


`ImageType = Filled` with a `FillMethod` and a `FillAmount` from 0 to 1 is how you draw a progress ring or bar out
of any sprite. Bind `sFillAmount` to an animated state and it fills smoothly.

## Skew

`Skew` on a background or image slants it the way the game's panels are slanted, and `sSkew` lets a parent pass its
skew down, which the buttons do for their content. `PreserveAspect` keeps a sprite's proportions when the box isn't
the sprite's shape. It is what you want on icons.

## Spinner

`Spinner` is a rotating icon, sized by its `FlexItem` and colored through its nested `Image`:

```csharp
new Spinner {
    FlexItem = {
        Size = 10.pt
    },

    Image = {
        sColor = Palette.Map(x => x.Primary)
    }
}
```

`RotationSpeed` sets how fast it turns and negative values turn it the other way. It's a field, not a property,
so it has no `s` binding. Set it from a callback if it needs to follow a state. `sEnabled` is the usual way to show
it while something loads, as the [primary button](/docs/sdk/primary-buttons) example did.

## WebImage

`WebImage` is an `Image` that loads from a URL:

<Playground preview="/assets/sdk/web-image.gif">
```csharp excerpt
new WebImage {
    FlexItem = {
        Size = new() { x = 20.pt, y = 20.pt }
    },

    Src = coverUrl,
    FallbackSprite = GameResources.CircleIcon,
    PreserveAspect = true
}
```
```csharp
class WebImages : ReactiveComponent {
    protected override GameObject Construct() {
        return new Layout {
            FlexController = {
                AlignItems = Align.Center,
                JustifyContent = Justify.Center,
                Gap = 6.pt
            },

            Children = {
                CreateImage(
                    "https://placehold.co/400x400/59bfff/ffffff/png?text=Cover"
                ),
                CreateImage(
                    "https://upload.wikimedia.org/wikipedia/commons/d/d3/Newtons_cradle_animation_book_2.gif"
                ),
                CreateImage("https://nowhere.invalid/cover.png")
            }
        }.Use();
    }

    private static WebImage CreateImage(string url) {
        return new WebImage {
            FlexItem = {
                Size = new() { x = 20.pt, y = 20.pt }
            },

            Src = url,
            FallbackSprite = GameResources.CircleIcon,
            PreserveAspect = true
        };
    }
}
```
</Playground>


Set `Src` and it loads in the background, showing a dark overlay with a spinner until it arrives, then fading the
overlay out. Set it again and the previous load is cancelled. Cached images skip the overlay entirely. Animated
images play, and `IsPlaying` and `IsFirstFrame` control them. `FallbackSprite` shows when loading fails, and
`OnLoadFailed` tells you about it. `StartAnimation` and `FinishAnimation` are the overlay's fade in and out, as
`Animation<WebImageAnimContext>` records you can replace or set to null to snap.
## Properties

These are `Image`'s, and `Background` forwards all of them to its image (minus `FillCenter`) on top of being a `Layout`. `WebImage` adds `Src`, `FallbackSprite`, `OnLoadFailed`, `StartAnimation`, `FinishAnimation`, `IsPlaying` and `IsFirstFrame`. `Spinner` exposes its `Image` for a nested initializer and a `RotationSpeed` field. Every property with a setter also has an `s`-version that takes a state.
